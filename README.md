# Tic-Tac-Toe React

A modern, interactive tic-tac-toe game built with React featuring game history and beautiful FontAwesome icons.

## 🎮 Live Demo

Play the game now: [https://kelsey-myers.github.io/tic-tac-toe-react](https://kelsey-myers.github.io/tic-tac-toe-react)

*(Desktop only)*

## ✨ Features

This tic-tac-toe game includes the following features:

- **Play tic-tac-toe!** - Classic 3x3 grid gameplay
- **Winner detection** - Indicates when a player has won the game with animated winner announcement
- **Game history** - Stores a game's history as a game progresses
- **Time travel** - Allows players to review a game's history and see previous versions of the game board
- **Beautiful icons** - Uses FontAwesome icons for X and O symbols
- **Responsive design** - Clean, modern styling optimized for desktop

## 🚀 Technologies Used

- **React** (16.13.1) - Component-based UI library
- **FontAwesome** - Icons for game symbols
- **CSS3** - Custom styling with animations
- **Create React App** - Build tooling and development server

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kelsey-myers/tic-tac-toe-react.git
   cd tic-tac-toe-react
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## 🎯 Usage

### Development Mode

Start the development server:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the game in your browser.

### Build for Production

Create a production build:

```bash
npm run build
```

### Deploy to GitHub Pages

Deploy the application:

```bash
npm run deploy
```

## 🎮 How to Play

1. Click on any empty square to place your symbol (X or O)
2. Players alternate turns automatically
3. First player to get three symbols in a row (horizontally, vertically, or diagonally) wins!
4. Use the history buttons on the right to jump back to any previous move
5. Click "Go to game start" to restart the game

## 🛠️ Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - **One-way operation** to eject from Create React App
- `npm run deploy` - Deploys the built app to GitHub Pages
